# Release 25

- Rebuilt the Loan Suite masthead around the supplied reference: scenario and dates on the first line, with Save, File actions, Loan tools, Live summary, and Full form on a compact second line.
- Replaced the File, Loan, Costs, Underwriting, and Results controls with compact line-icon navigation matching the Income Calculator, and added a Full workspace after Results.
- Added a six-number live summary strip for price, renovation budget, loan, rate, payment, and cash to close above the existing MMW calculation cards.
- Redesigned the scenario name and saved-scenario selector as one dark, modern control using a distinct Manrope-based type treatment.
- Added a third appearance control that cycles Light, Dark, and OLED surfaces independently of the ten color themes and five input tones. Dark remains the default and theme accents are preserved.
- Rebuilt File actions, Loan tools, and Income file actions as structured dark popouts with icons, descriptions, keyboard dismissal, and clearer grouping.
- Added a continuous Full-file view containing live File & Property, Loan & Renovation, Costs & Escrow, Underwriting, and Results sections with direct links back to their editable source forms.
- Hardened the Setup Worksheet against narrow-screen and zoom layout failures. At 1360px and below, the live summary becomes a drawer so the form remains full-width and vertically stacked.
- Preserved universal freeform input handling and the existing calculation engines.
